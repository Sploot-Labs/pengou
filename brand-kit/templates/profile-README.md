On fabrique des outils, des bibliothèques et des expérimentations autour de l'**IA** — du vrai travail d'ingénierie, sans le gatekeeping.

Un débutant qui ouvre sa première pull request mérite le même accueil qu'un mainteneur chevronné. Sous la douceur, de l'exigence ; derrière le sourire, des tests qui passent. 🐾

### 🐾 Contribuer

Première contribution open source ? **C'est exactement ici qu'on veut t'accueillir.**
Cherche le label [`good first issue`](https://github.com/search?q=org%3Asplootlabs+label%3A%22good+first+issue%22&type=issues) — on t'accompagne pas à pas, et on célèbre chaque PR.
