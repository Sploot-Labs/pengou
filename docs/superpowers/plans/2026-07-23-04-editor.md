# Éditeur de quiz — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Permettre à un hôte authentifié de créer/éditer ses quiz et leurs questions (4 types via un registre de stratégies branchables), à travers une API HTTP protégée et **strictement scopée à son tenant** — les tables enfant (question) étant scopées par **jointure** sur le quiz parent.

**Architecture:** Un package `@splootlabs/quiz` porte le **registre de types de question** (validation du payload par type ; le scoring viendra au Plan 5). Le module Data (`@splootlabs/db`) gagne les repos `quiz` (update/delete) et `question` (CRUD + reorder), chaque repo enfant vérifiant d'abord que le quiz parent appartient au tenant du scope. Le serveur expose des routes REST derrière un décorateur `requireUser` (session Better Auth → `request.user`) et un helper `requestScope` (résout le `tenantScope` depuis le userId de la session + le tenant actif). Joueurs anonymes inchangés.

**Tech Stack:** TypeScript, Drizzle/Postgres, Fastify, Better Auth (session), zod (validation payload), Vitest + testcontainers.

## Global Constraints

- **Isolation multi-tenant non négociable** : toute route/rép dérive le `tenantId` du **scope serveur** (session → membership), JAMAIS de l'input client. Les repos `question` scopent **par jointure sur `quiz.tenant_id`** (les tables enfant n'ont pas de `tenant_id`).
- **`requireUser`** : le userId vient de la **session** (Better Auth), jamais d'un champ client. En multi, le tenant actif vient d'un header `x-tenant-id` **validé par membership** (`resolveTenantId`).
- **Registre de types** : ajouter un type = un module de stratégie, sans toucher aux routes. Payload stocké en JSON (`question.payload`).
- **4 types MVP** : `mcq` (2–6 options, ≥1 correcte), `truefalse`, `text` (≥1 réponse acceptée, normalisée), `slider` (min<max, min≤correct≤max, step optionnel).
- **`user.id` est `text`** (Better Auth) ; `quiz.owner_id`/`tenant_id` en place (Plan 2/3).
- ESM/NodeNext, `.js` sur imports relatifs, TS strict, scope `@splootlabs/*`, Postgres, tests testcontainers (Docker requis).

import type { QuestionType, QuestionTypeDef } from './types.js'
import { mcq } from './mcq.js'
import { truefalse } from './truefalse.js'
import { text } from './text.js'
import { slider } from './slider.js'

export const questionTypes: Record<QuestionType, QuestionTypeDef> = { mcq, truefalse, text, slider }

export function validateQuestionPayload(type: QuestionType, raw: unknown): unknown {
  const def = questionTypes[type]
  if (!def) throw new Error(`type de question inconnu : ${type}`)
  return def.validatePayload(raw)
}

export async function updateQuiz(scope: TenantScope, id: string, patch: Partial<{ title: string; description: string | null; cover: string | null }>): Promise<Quiz | null> {
  const [row] = await scope.db.update(schema.quiz)

    .where(and(eq(schema.quiz.id, id), eq(schema.quiz.tenantId, scope.tenantId)))

  return row ?? null
}

export async function deleteQuiz(scope: TenantScope, id: string): Promise<boolean> {
  const rows = await scope.db.delete(schema.quiz)
    .where(and(eq(schema.quiz.id, id), eq(schema.quiz.tenantId, scope.tenantId)))
    .returning({ id: schema.quiz.id })
  return rows.length > 0
}

`packages/db/src/repos/question.ts`
```ts
import { and, eq, inArray, sql } from 'drizzle-orm'
import { schema } from '../index.js'
import type { TenantScope } from '../tenant.js'
import { getQuiz } from './quiz.js'

export type Question = typeof schema.question.$inferSelect

type CreateInput = { type: 'mcq' | 'truefalse' | 'text' | 'slider'; prompt: string; timeLimit: number; payload: unknown; media?: string | null; orderIndex?: number }

// Garde-fou multi-tenant : le quiz parent DOIT appartenir au tenant du scope.
async function assertQuizInTenant(scope: TenantScope, quizId: string): Promise<boolean> {
  return (await getQuiz(scope, quizId)) !== null
}

export async function createQuestion(scope: TenantScope, quizId: string, input: CreateInput): Promise<Question | null> {
  if (!(await assertQuizInTenant(scope, quizId))) return null
  const orderIndex = input.orderIndex ?? (await nextOrderIndex(scope, quizId))
  const [row] = await scope.db.insert(schema.question).values({
    quizId, type: input.type, prompt: input.prompt, timeLimit: input.timeLimit,
    payload: input.payload as never, media: input.media ?? null, orderIndex,
  }).returning()
  return row
}

export async function listQuestions(scope: TenantScope, quizId: string): Promise<Question[] | null> {
  if (!(await assertQuizInTenant(scope, quizId))) return null
  return scope.db.select().from(schema.question)
    .where(eq(schema.question.quizId, quizId))
    .orderBy(schema.question.orderIndex)
}

export async function updateQuestion(scope: TenantScope, quizId: string, questionId: string, patch: Partial<{ prompt: string; timeLimit: number; payload: unknown; media: string | null }>): Promise<Question | null> {
  if (!(await assertQuizInTenant(scope, quizId))) return null
  const [row] = await scope.db.update(schema.question)
    .set({ ...patch, payload: patch.payload as never })
    .where(and(eq(schema.question.id, questionId), eq(schema.question.quizId, quizId)))
    .returning()
  return row ?? null
}

export async function deleteQuestion(scope: TenantScope, quizId: string, questionId: string): Promise<boolean> {
  if (!(await assertQuizInTenant(scope, quizId))) return false
  const rows = await scope.db.delete(schema.question)
    .where(and(eq(schema.question.id, questionId), eq(schema.question.quizId, quizId)))
    .returning({ id: schema.question.id })
  return rows.length > 0
}

export async function reorderQuestions(scope: TenantScope, quizId: string, orderedIds: string[]): Promise<boolean> {
  if (!(await assertQuizInTenant(scope, quizId))) return false
  await scope.db.transaction(async (tx) => {
    for (let i = 0; i < orderedIds.length; i++) {
      await tx.update(schema.question).set({ orderIndex: i })
        .where(and(eq(schema.question.id, orderedIds[i]), eq(schema.question.quizId, quizId)))
    }
  })
  return true
}

async function nextOrderIndex(scope: TenantScope, quizId: string): Promise<number> {
  const [row] = await scope.db.select({ max: sql<number>`coalesce(max(${schema.question.orderIndex}), -1)` })
    .from(schema.question).where(eq(schema.question.quizId, quizId))
  return (row?.max ?? -1) + 1
}
```
(Le `patch.payload as never` évite un souci de typage jsonb ; la validation du payload se fait à la couche route via `@splootlabs/quiz`, pas ici.)

`apps/server/src/require-user.ts`
```ts
import type { FastifyInstance, FastifyRequest, FastifyReply } from 'fastify'
import { fromNodeHeaders } from 'better-auth/node'
import { resolveTenantId, tenantScope, type Db, type TenantScope } from '@splootlabs/db'
import type { AppConfig } from '@splootlabs/shared'
import type { Auth } from '@splootlabs/auth'

declare module 'fastify' {
  interface FastifyRequest { user: { id: string; email: string } }
  interface FastifyInstance { auth: Auth }
}

export function registerRequireUser(app: FastifyInstance, auth: Auth): void {
  if (!app.hasDecorator('auth')) app.decorate('auth', auth)
}

export async function requireUser(request: FastifyRequest, reply: FastifyReply): Promise<void> {
  const session = await request.server.auth.api.getSession({ headers: fromNodeHeaders(request.headers) })
  if (!session?.user) { reply.code(401).send({ error: 'Non authentifié.' }); return }
  request.user = { id: session.user.id, email: session.user.email }
}

export async function requestScope(request: FastifyRequest, db: Db, config: AppConfig): Promise<TenantScope> {
  const explicitTenantId = typeof request.headers['x-tenant-id'] === 'string' ? (request.headers['x-tenant-id'] as string) : undefined
  const tenantId = await resolveTenantId(db, config, { userId: request.user.id, explicitTenantId })
  return tenantScope(db, tenantId)
}
```
> Note : `resolveTenantId` lève « accès refusé » en multi sans membership valide — les routes convertiront cette erreur en 403 (Task 4).
