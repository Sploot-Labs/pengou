# Fondations — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Poser le squelette du monolithe TypeScript modulaire : un serveur Node qui sert le SPA React, une configuration pilotée par 3 axes orthogonaux (tenancy / base / scaling), une liaison temps réel Socket.IO, et une image Docker « self-host zéro config ».

**Architecture:** Monorepo pnpm avec un serveur Fastify unique qui expose l'API HTTP, attache Socket.IO sur le même port, et sert le build statique du SPA React. Le code partagé (config, types) vit dans des packages isolés réutilisables. Aucune logique métier ici — uniquement les fondations sur lesquelles les plans 2 à 8 s'appuient.

**Tech Stack:** TypeScript, pnpm (workspaces), Fastify, Socket.IO, React + Vite, Vitest, Docker.

## Global Constraints

- **Langage** : TypeScript partout. `"strict": true` dans tous les `tsconfig`.
- **Un seul processus / une seule image Docker** : le serveur sert aussi le SPA.
- **3 axes de config orthogonaux** (valeurs par défaut self-host) :
  - `TENANCY_MODE` = `single` (défaut) | `multi`
  - `DATABASE_URL` = `file:./data/app.db` (SQLite, défaut) | URL Postgres
  - Scaling = `memory` si `REDIS_URL` absent (défaut) | `redis` si présent
- **Node** : ≥ 20.
- **Test runner** : Vitest partout.
- **Package manager** : pnpm (workspaces).
- **Scope prefix des packages** : `@kahoot/*`.

import { z } from 'zod'

const EnvSchema = z.object({
  NODE_ENV: z.enum(['development', 'test', 'production']).default('development'),
  PORT: z.coerce.number().int().positive().default(3000),
  TENANCY_MODE: z.enum(['single', 'multi']).default('single'),
  DATABASE_URL: z.string().min(1).default('file:./data/app.db'),
  REDIS_URL: z.string().min(1).optional(),
  SESSION_SECRET: z.string().min(16).default('dev-secret-change-me-please!!'),
})

export type AppConfig = {
  nodeEnv: 'development' | 'test' | 'production'
  port: number
  tenancyMode: 'single' | 'multi'
  databaseUrl: string
  redisUrl?: string
  sessionSecret: string
  scaling: 'memory' | 'redis'
}

export function loadConfig(env: Record<string, string | undefined> = process.env): AppConfig {
  const parsed = EnvSchema.parse(env)
  return {
    nodeEnv: parsed.NODE_ENV,
    port: parsed.PORT,
    tenancyMode: parsed.TENANCY_MODE,
    databaseUrl: parsed.DATABASE_URL,
    redisUrl: parsed.REDIS_URL,
    sessionSecret: parsed.SESSION_SECRET,
    scaling: parsed.REDIS_URL ? 'redis' : 'memory',
  }
}
```

import { io as ioClient, type Socket } from 'socket.io-client'
import { buildServer } from './app'
import { attachRealtime } from './realtime'
import { loadConfig } from '@kahoot/shared'

let client: Socket | undefined

  client?.disconnect()
})

describe('Socket.IO ping/pong', () => {
  it('répond pong à ping:test', async () => {
    const app = buildServer(loadConfig({ NODE_ENV: 'test' }))
    attachRealtime(app)
    await app.listen({ port: 0, host: '127.0.0.1' })
    const address = app.server.address()
    if (!address || typeof address === 'string') throw new Error('pas d\'adresse')

    client = ioClient(`http://127.0.0.1:${address.port}`)

    const reply = await new Promise<string>((resolve) => {
      client!.emit('ping:test', (msg: string) => resolve(msg))
    })

    expect(reply).toBe('pong')
    await app.close()
  })
})

export function attachRealtime(app: FastifyInstance): Server {
  const io = new Server(app.server, { cors: { origin: true } })

  io.on('connection', (socket) => {

    })
  })

  return io
}

import type { FastifyInstance } from 'fastify'
import fastifyStatic from '@fastify/static'
import { join } from 'node:path'

export function registerStatic(app: FastifyInstance, webDistDir: string): void {
  app.register(fastifyStatic, { root: webDistDir, wildcard: false })

  // Fallback SPA : toute route non-API renvoie index.html
  app.setNotFoundHandler((req, reply) => {
    if (req.url.startsWith('/api') || req.url.startsWith('/health')) {
      reply.code(404).send({ error: 'not found' })
      return
    }
    reply.sendFile('index.html', webDistDir)
  })
}
```

# Le build du SPA est servi depuis ./public
COPY --from=build /app/apps/web/dist ./apps/server/public
